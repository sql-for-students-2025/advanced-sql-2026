Программа обучения SQL для магистров (12 занятий по 1.5 часа)

План занятий:

Занятие 1: Основы баз данных и СУБД
Теория:
- Что такое база данных (БД)
- Системы управления базами данных (СУБД)
- Виды БД: реляционные vs нереляционные
- Обзор реляционных СУБД: OLTP vs OLAP

Занятие 2: Основы SQL. Простые SELECT-запросы
Теория:
- Структура SQL-запроса
- Основные команды: SELECT, FROM, WHERE
- Сортировка (ORDER BY)
- Ограничение количества строк (LIMIT, OFFSET)

Занятие 3: Типы данных
Теория:
- Типы данных

Занятие 4: Создание таблиц. Операции Insert, Delete, Update, Truncate
Теория:
- Способы создания таблиц
- Ограничения (Constraints)
- Операторы Insert, Delete, Update, Truncate

Занятие 5: Агрегатные функции и группировка
Теория:
- Функции: COUNT, SUM, AVG, MIN, MAX
- Группировка (GROUP BY)
- Фильтрация групп (HAVING)

Занятие 6: Подзапросы
Теория:
- Вложенные запросы
- Подзапросы в WHERE, FROM, SELECT

Занятие 7: Соединение таблиц (JOINs)
Теория:
- Виды соединений: INNER, LEFT/RIGHT, FULL, CROSS JOIN
- Алиасы таблиц

Занятие 8: Временные таблицы и CTE
Теория:
- Временные таблицы
- CTE (WITH ... AS)
- Разница и применение

Занятие 9: Оконные функции
Теория:
- Функции: ROW_NUMBER(), RANK(), DENSE_RANK(), LEAD(), LAG()
- PARTITION BY, ORDER BY в окнах

Занятие 10: Индексы, план запроса, оптимизация
Теория:
- Что такое индексы
- Типы индексов (B-tree, Hash, GiST, GIN)
- Когда использовать индексы
- План выполнения запроса (EXPLAIN)
- Разбор кейса с оптимизацией

Занятие 11: Процедуры и функции в PostgreSQL.
Теория:
- Процедуры и функции в PostgreSQL

Бонусное занятие: Представления (View)
- Для чего нужны View
- Создание View
