### Задачи по таблице `transactions` (Транзакции)

1. **Выручка по магазинам**
   Выведите `store_id` и общую сумму всех чеков (`SUM(cheque_sum)`) для каждого магазина. Отсортируйте по убыванию выручки.

2. **Средний чек по дням**
   Выведите дату (только день из `dt`) и среднюю сумму чека (`AVG(cheque_sum)`) за этот день. Отсортируйте по дате.

3. **Количество транзакций по клиентам**
   Выведите `customer_id` и количество совершенных им транзакций (`COUNT(id)`). Оставьте только тех клиентов, у которых больше 5 транзакций (используйте `HAVING`).

4. **Максимальный и минимальный чек**
   Для каждого магазина (`store_id`) выведите максимальную и минимальную сумму чека (`MAX(cheque_sum)`, `MIN(cheque_sum)`).

5. **Общее количество проданных товаров по магазинам**
   Выведите `store_id` и суммарное количество товаров во всех чеках (`SUM(qnty)`). Отфильтруйте магазины, где общее количество проданных товаров превышает 1000 штук.

6. **Количество чеков по часам**
   Выведите час совершения транзакции (из `dt`) и количество чеков (`COUNT(id)`) за этот час. Отсортируйте по часу.

7. **Средняя сумма чека по клиентам**
   Выведите `customer_id` и среднюю сумму его чека (`AVG(cheque_sum)`). Оставьте только тех клиентов, у которых средний чек выше 5000.

### Задачи по таблице `transactions_details` (Детали транзакций)

8. **Топ товаров по количеству продаж**
   Выведите `art_id` (артикул) и общее количество проданных единиц этого товара (`SUM(qnty)`). Отсортируйте по убыванию количества.

9. **Количество покупок по магазинам**
   Выведите `store_id` и количество уникальных транзакций (позиций) в этом магазине (`COUNT(id)`).

10. **Среднее количество товара в одной позиции чека**
    Выведите `art_id` и среднее количество этого товара в одной покупке (`AVG(qnty)`). Оставьте только товары, которые в среднем покупают более 2 штук за раз.

11. **Активность клиентов по магазинам**
    Выведите `customer_id` и `store_id`, а также количество раз, когда этот клиент совершал покупку в этом магазине (`COUNT(id)`). Отсортируйте по `customer_id`, затем по `store_id`.

12. **Максимальная покупка одного товара**
    Для каждого артикула (`art_id`) выведите максимальное количество, которое было куплено за один раз (`MAX(qnty)`).

13. **Общее количество проданных единиц по дням**
    Выведите дату (день из `dt`) и суммарное количество проданных единиц товара (`SUM(qnty)`) за этот день. Отфильтруйте дни, где было продано более 500 единиц.

### Задачи по таблице `stores` (Магазины)

14. **Количество магазинов по городам**

15. **Средняя площадь магазинов по форматам**
    Выведите `frmt` (формат) и среднюю площадь магазинов этого формата (`AVG(square)`).

16. **Количество магазинов по форматам и городам**
    Выведите `frmt` и `city_id`, а также количество магазинов (`COUNT(id)`) для каждой комбинации. Отсортируйте по формату и городу.

17. **Самый большой и самый маленький магазин по форматам**
    Для каждого формата (`frmt`) выведите максимальную и минимальную площадь магазина (`MAX(square)`, `MIN(square)`).

18. **Количество активных магазинов по городам**
    Выведите `city_id` и количество магазинов, у которых `close_dt IS NULL` (активные). Используйте `COUNT` с условием или `SUM(CASE WHEN ...)`.
