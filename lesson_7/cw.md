## Блок 1. Базовые CTE (одна CTE)

1. Выведите список клиентов, у которых есть хотя бы одна транзакция, и для каждого укажите количество его транзакций и общую сумму покупок. Используйте CTE для предварительного агрегирования данных по клиентам.

2. Определите магазины, у которых средняя сумма чека выше, чем у магазина с идентификатором 1. Сначала получите агрегированную таблицу по магазинам в CTE.

3. Найдите товары, которые продавались в магазинах, расположенных в городах с населением более 500 000 человек. Используйте CTE для отбора подходящих магазинов.

4. Выведите клиентов, которые совершали покупки в магазинах формата «гипермаркет», и укажите суммарную сумму их покупок. Используйте CTE для отбора нужных магазинов.

5. Для каждой категории товаров определите количество проданных единиц и общую выручку. Используйте CTE для агрегирования продаж по товарам, а затем соедините с категориями.

6. Найдите бренды, у которых средняя цена товара выше средней цены по всем брендам. Сначала получите средние цены по брендам в CTE.

7. Выведите города, в которых количество магазинов превышает среднее количество магазинов на город. Используйте CTE для подсчёта магазинов по городам.

8. Определите клиентов, которые покупали товары более чем из трёх категорий. Используйте CTE для подсчёта уникальных категорий по клиентам.

9. Найдите магазины, у которых количество транзакций больше, чем количество транзакций у магазина с максимальной площадью. Используйте CTE для определения магазина-эталона.

10. Выведите товары, которые ни разу не продавались в магазинах, открытых после 2020 года. Используйте CTE для отбора «новых» магазинов.

## Блок 2. Несколько CTE (цепочки)

11. Определите клиентов, у которых средняя сумма чека выше средней суммы чека по их городу. Используйте две CTE: одну для агрегации по клиентам, другую — для агрегации по городам.

12. Найдите категории, в которых есть товары дороже средней цены по категории, и выведите количество таких товаров. Используйте CTE для расчёта средней цены по категориям, затем CTE для подсчёта «дорогих» товаров.

13. Выведите топ-5 брендов по суммарной выручке и для каждого укажите количество проданных единиц и среднюю цену товара. Используйте цепочку CTE: продажи → агрегация по брендам → топ-5.

14. Определите магазины, которые продали больше товаров, чем средний магазин, и при этом расположены в городах с населением менее 100 000 человек. Используйте CTE для агрегации по магазинам и CTE для отбора городов.

15. Найдите клиентов, которые покупали товары только одного бренда, и выведите этот бренд. Используйте две CTE: одна — уникальные пары «клиент-бренд», вторая — клиенты с единственным брендом.

16. Для каждого формата магазина определите среднюю сумму чека и сравните её со средней суммой чека по всем форматам. Используйте CTE для агрегации по форматам и CTE для общей средней.

17. Выведите товары, которые продавались в магазинах всех форматов (то есть хотя бы по одному разу в каждом формате). Используйте CTE для подсчёта форматов по товарам.

18. Определите клиентов, у которых максимальная сумма чека превышает среднюю сумму чека по их городу, и выведите разницу. Используйте цепочку CTE: агрегация по клиентам → агрегация по городам → сравнение.

19. Найдите категории, у которых доля продаж (в штуках) превышает 10% от общего количества проданных товаров. Используйте CTE для агрегации по категориям и CTE для общего итога.

20. Выведите магазины, у которых средняя площадь больше средней площади по их городу, и укажите разницу. Используйте две CTE: агрегация по городам и агрегация по магазинам.

## Блок 3. Временные таблицы (`CREATE TEMP TABLE`)

21. Создайте временную таблицу с агрегированными данными по клиентам (количество транзакций, сумма покупок). Затем выведите клиентов, у которых сумма покупок выше средней по временной таблице.

22. Создайте временную таблицу с товарами, которые продавались хотя бы один раз. Затем выведите категории, в которых все товары присутствуют в этой временной таблице.

23. Создайте временную таблицу с магазинами, у которых средняя сумма чека выше 1000. Затем выведите города, в которых есть хотя бы один такой магазин.

24. Создайте временную таблицу с агрегацией по дням (выручка, количество чеков). Затем выведите дни, в которые выручка была выше средней по временной таблице.

25. Создайте временную таблицу с клиентами, у которых есть email. Затем выведите количество таких клиентов по полу.

26. Создайте временную таблицу с топ-10 товаров по количеству продаж. Затем выведите категории, к которым относятся эти товары, и суммарное количество продаж по категориям.

27. Создайте временную таблицу с брендами, у которых больше 5 товаров. Затем выведите среднюю цену товаров этих брендов.

28. Создайте временную таблицу с магазинами, открытыми после 2015 года. Затем выведите форматы этих магазинов и их количество.

29. Создайте временную таблицу с клиентами, у которых средний чек выше 5000. Затем выведите города (по магазинам, где они покупали) и количество таких клиентов в каждом городе.

30. Создайте временную таблицу с агрегацией по форматам магазинов (количество магазинов, средняя площадь, суммарная выручка). Затем выведите форматы, у которых выручка выше средней по временной таблице, и укажите их долю в общей выручке.

## Блок 4. Комбинированные задачи (CTE + временные таблицы + JOIN)

31. Создайте временную таблицу с агрегацией по клиентам. Используя CTE, определите клиентов, чья сумма покупок выше средней по временной таблице, и выведите их любимую категорию (по количеству покупок).

32. Создайте временную таблицу с продажами по магазинам и категориям. Используя CTE, найдите для каждого магазина категорию с максимальной выручкой.

33. Создайте временную таблицу с клиентами и их городами (через магазины). Используя CTE, определите город с наибольшим количеством уникальных клиентов.

34. Создайте временную таблицу с товарами и их продажами. Используя CTE, определите товары, которые продавались в магазинах всех городов, где есть магазины сети.

35. Создайте временную таблицу с агрегацией по брендам и категориям. Используя CTE, найдите бренд с максимальной средней ценой в каждой категории.

## Блок 6. Сложные аналитические задачи

36. Постройте отчёт: для каждого месяца выведите выручку, количество чеков, средний чек и сравнение с предыдущим месяцем (в процентах). Используйте CTE для агрегации по месяцам и оконные функции для сравнения.

37. Постройте отчёт: для каждого клиента выведите его любимую категорию (по количеству покупок), сумму покупок в этой категории и долю этой категории в общей сумме покупок клиента. Используйте CTE для агрегации по клиентам и категориям.
